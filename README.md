# book-viewer

自炊本の PDF を読むためのビューア。見開き・右綴じ・表紙単独といった「開き方」を
切り替えて **PDF 本体に書き込める**（プレビュー・Acrobat 等の他のリーダーにも伝わる）。
読んでいた位置は本ごとに記憶し、表示中の PDF が書き換えられたら（TeX の再コンパイル等）
自動で読み込み直す。

画面は左から **フォルダツリー | ページサムネール | ページ**。フォルダツリーは Windows エクスプローラー風、
それ以外の操作・用語・ショートカットは **Adobe Acrobat に揃えている**。既定のウィンドウは FHD（1920×1080。
画面が小さければ収まる大きさ）。アプリ内の文字はすべて 16 pt（メニューバーとタイトルバーは macOS が描くので対象外）。

PySide6 + QtPdf（表示）+ pikepdf（開き方の書き込み）製。

## 導入・実行（uv）

```bash
uv tool install --editable .     # book-viewer コマンドを導入（ソース編集が即反映）
book-viewer <フォルダ>            # 本棚として開く
book-viewer <本.pdf>              # その本を開く（本棚はそのフォルダ）
book-viewer                       # 前回のフォルダを開く
```

開発時:

```bash
uv run book-viewer <フォルダ>
uv run pytest                     # 見開きの組み方・PDF 書き込み・状態保存のテスト
```

## 使い方

**本棚（左）** … Windows エクスプローラーのナビゲーションウィンドウ風のフォルダツリー。

```
  ..                ← 起動フォルダを 1 つ上へ付け替える
▸ 📁 <起動フォルダ>
▸ 🏠 ホーム
▾ 💻 この Mac
    ▸ Macintosh HD / 外付けドライブ / ネットワークドライブ（接続先つき）
```

- PDF 以外のファイルと隠しファイル（Finder と同じく `/bin`・`/usr`・`~/Library` なども）は出さない。並びは自然順（「2巻」→「10巻」）
- フォルダはクリックで開閉、⌘↑ で親フォルダを選択して閉じる、⇧⌘O で任意のフォルダをツリー上で開く
- `..` をクリックすると起動フォルダが 1 つ上に替わり、元のフォルダを開いて選択した状態になる（起動フォルダを選択中の ⌘↑ も同じ）
- PDF をクリックで開き、前回の位置から再開する。右端は読書の進捗（%）、マウスを乗せると表紙のサムネイル
- 開いたフォルダの追加・削除、ドライブの抜き差しは自動で反映される
- 起動時の既定フォルダは、前回最後に開いた本のフォルダ

**メニューとショートカット（Acrobat と同じ）**

| メニュー | 項目 | キー |
|---|---|---|
| ファイル | 開く…（PDF） / フォルダを開く… | ⌘O / ⇧⌘O |
| | 閉じる | ⌘W |
| | 文書のプロパティ…（開き方・綴じ方を PDF に書き込む） | ⌘D |
| 表示 › ページナビゲーション | 最初 / 前 / 次 / 最後のページ、ページへ移動… | ⇧⌘N（ページへ移動） |
| 表示 › ページ表示 | 単一ページ表示 / 見開きページ表示 / 見開きページ表示で表紙を表示 | |
| 表示 › 表示切り替え | ナビゲーションパネル › ページサムネール、フォルダツリー | F4（サムネール） |
| 表示 › ズーム | ズームイン / ズームアウト | ⌘+ / ⌘- |
| | ページレベルにズーム / 実際のサイズ（100%） / 幅に合わせる | ⌘0 / ⌘1 / ⌘2 |
| 表示 | 全画面モード | ⌘L（Esc で解除） |

ツールバーは 開く ｜ ページサムネール ｜ ↑ ↓ ページ番号欄 / 総ページ ｜ − 倍率 ▾ + ｜ 単一ページ表示・見開きページ表示 ｜ 全画面モード。
ページ番号欄に数字を入れて Enter でそのページへ。
「見開きページ表示」は ▾ 付きのプルダウン。本体で見開きに切り替え、▾ で**表紙あり / 表紙なし**を選ぶ（表示メニューのチェックと連動）。

**ページサムネール** … 全ページの縮小表示。クリックでそのページへ移動し、表示中のページ（見開きなら 2 ページ）を
選択状態で示す。パネルを広げると複数列になる。表示 / 非表示は F4・ツールバー・パネルの ✕ で切り替え、次回も同じ状態で開く。
描くのは画面に見えているページだけ（別スレッド）なので、数百ページの本でもすぐ開く。

**開き方と綴じ方** … Acrobat と同じく 2 段構え。

- 表示 › ページ表示 … その場の表示だけを変える（PDF は書き換えない）
- ⌘D 文書のプロパティ … 初期値はいま見えている表示。「開き方 › ページレイアウト」（単一ページ / 見開きページ / 見開きページ（表紙））と
  「詳細設定 › 綴じ方」（左 / 右）を OK で **PDF に書き込み**、表示にも反映する。縦書きの本は綴じ方を「右」に

**拡大・縮小** … 既定はページレベル（組全体を収める）。倍率欄は一覧から選ぶか数字を入れて Enter。
⌘+ホイール・トラックパッドのピンチでも変えられる。倍率は次回起動時も引き継ぐ。
はみ出したときは Acrobat の単一ページ表示と同じく、ホイール・↑↓・Space でページ内をスクロールし、
端でさらに送ると次 / 前の組へ（前へ戻ったときはその組の下端から）。ドラッグで表示位置を動かせる
（クリックだけならページ送り）。400% まで。高倍率では描画の画素数を上限（4000 万画素）で打ち切り、少し拡大して貼る。

**ページ送りの向き（縦書き / 横書き）** … 綴じ方に従う。右綴じ（縦書き）は ← で次、左半分のクリックで次、
右へスワイプで次。左綴じ（横書き）はその逆。綴じ方は次の順で決める。

1. PDF に書かれた綴じ方（⌘D で保存したもの）
2. 書かれていなければ、OCR などのテキストがある本は文字の並びで判定（縦書きなら右綴じで表示）
3. 画像だけの本は判定しない（左綴じ）。縦書きの本は ⌘D で一度「綴じ方: 右」にすれば次からその向きで開く

画像から行の向きを推定する方法も試したが、zz_Books 950 冊でページごとに判定が割れ、誤判定すると
矢印キーが逆になるので採っていない。

**読書**

| 操作 | 動作 |
|---|---|
| → / ← | 綴じ方向に沿って次 / 前（右綴じでは ← が「次」） |
| Space・↓ / ⇧Space・↑ | 次 / 前（拡大時はページ内をスクロールし、端で次 / 前へ） |
| PageDown / PageUp | 次 / 前の組 |
| Home / End | 先頭 / 末尾 |
| ホイール・トラックパッド | 縦スクロールは下で次。横スワイプは綴じ方向に沿う。1 ノッチ相当ごとに 1 組（慣性スクロールは無視） |
| クリック / ドラッグ | 左半分 = ←、右半分 = → / 拡大時は表示位置を動かす |

**自動再読込** … 表示中の PDF が変更されると、サイズと更新時刻が 400 ms 変わらず、かつ
末尾に `%%EOF` があるのを確かめてから読み直す（書き込み途中のファイルは読まない。読めなければ
最大約 20 秒再試行）。ページ位置と、その場の表示（ページ表示）はそのまま保つ。

`luatex-pdf`（zeus でコンパイルし scp で PDF を取得）で動作を確認済み。scp は既存ファイルを
先頭から上書きするため、転送が止まった瞬間の書きかけを読まないよう `%%EOF` を条件にしている
（pdfium は壊れた PDF も開けてしまい、ページ数の少ない版を読むことになる）。

## PDF に書き込む内容

PDF 標準（ISO 32000）のカタログ項目だけを書き換える。

| 設定 | 書き込む値 |
|---|---|
| 単ページ | `/PageLayout /SinglePage` |
| 見開き・表紙単独 | `/PageLayout /TwoPageRight` |
| 見開き・表紙なし | `/PageLayout /TwoPageLeft` |
| 右綴じ / 左綴じ | `/ViewerPreferences << /Direction /R2L >>` / `/L2R` |

- 書き込みは「同じフォルダの一時ファイルに保存 → ページ数と値を読み戻して検証 → 置き換え」。
  途中で失敗しても元のファイルは壊れない
- 変更前の値は `~/.local/state/book-viewer/prefs-log.jsonl` に追記される（元に戻すときの控え）
- ほかのリーダーがこれらの値をどこまで尊重するかはリーダーによって違う

**TeX で作る PDF** は再コンパイルのたびに書き込んだ設定が消える。ソース側で指定する
（zeus の LuaLaTeX で `/TwoPageRight` と `/Direction /R2L` が出力されることを確認済み）:

```latex
\usepackage[pdfpagelayout=TwoPageRight, pdfdirection=R2L]{hyperref}
```

## 状態ファイル

| 場所 | 内容 |
|---|---|
| `~/.local/state/book-viewer/state.json` | 本ごとの読書位置（キーは絶対パス。ファイル名を変えると引き継がれない）、前回のフォルダ、ページサムネール・フォルダツリーの表示 / 非表示、ズームの倍率 |
| `~/.local/state/book-viewer/prefs-log.jsonl` | PDF への書き込み履歴（変更前 / 変更後の値） |
| `~/.cache/book-viewer/thumbs/` | サムネイル（消しても再生成される） |

`XDG_STATE_HOME` が設定されていればそちらを使う。

## 端末から切り離して起動（任意）

```zsh
book-viewer() { command book-viewer "$@" </dev/null &>/dev/null &! }
```
